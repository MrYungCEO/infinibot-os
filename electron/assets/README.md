# InfiniBot Desktop - Assets

All icons use the InfiniBot mark (the gold infinity globe, same art as
`ui/public/favicon.ico` and `ui/public/infinibot-logo.png`).

| File | Size | Purpose |
|------|------|---------|
| `icon.png` | 512x512 | Window icon (Linux, fallback) |
| `icon.ico` | 16-256 multi-size | Windows app, installer and uninstaller icon |
| `tray-icon.png` | 32x32 | System tray icon |
| `infinibot-icon-dark-*.png` | 16-1024 | Source sizes for the above and for `../build/icons/` (Linux) |
| `infinibot-logo.png` | 1024x1024 | Full logo |

Installer artwork lives in `../build/`: `installerSidebar.bmp` /
`uninstallerSidebar.bmp` (164x314) and `installerHeader.bmp` (150x57), 24-bit BMP.
The Browser Relay extension icons (`assets/chrome-extension/icons/`) use the
same mark.
