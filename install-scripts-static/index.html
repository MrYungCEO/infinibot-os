🔥 InfiniBot

Install the infinibot npm package and open setup, in one line

🪟 Windows (PowerShell)

iwr -useb https://infinibotos.com/install.ps1 | iex

🍎 macOS / 🐧 Linux

curl -fsSL https://infinibotos.com/install.sh | bash

📦 npm (any OS with Node 22.12+ and git)

npm i -g infinibot && infinibot onboard
