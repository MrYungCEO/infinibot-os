Content Studio

Run your social content like a studio: a page per channel, scripts, reel intelligence and a CMO agent.

Who it's for

Anyone posting to Instagram, TikTok, YouTube or LinkedIn who wants ideas, scripts and posting in one pipeline.

What it does

  • One content page per channel with scripts, ideas, goals and brand voice
  • Reel library with metrics, transcripts and viral-format scoring
  • CMO, Content Director, Scriptwriter, Brand Designer and Video Editor agents

How to start

  1. Install Content Studio from the marketplace.
  2. Create a page for each channel and connect Instagram (Graph API token) if you want live stats.
  3. Let the CMO agent draft scripts from your research and saved viral examples, then queue posts.

What you need

  • Instagram Graph API token for live follower and reach stats (optional)
  • The reel pipeline (download, transcription, scoring) needs a self-hosted install with Python, gallery-dl and Whisper

Questions

Does it post for me?

It runs the pipeline from idea to queued post. Live posting to phones goes through Droid Swarm with an approval step.

What happens if I turn it off?

Every page hides and background sync stops. Your data stays where it is.
