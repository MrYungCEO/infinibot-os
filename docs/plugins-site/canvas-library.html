HoloCanvas

Turn reports into narrated, shareable walkthroughs on an infinite canvas.

Who it's for

Agencies and consultants who present proposals, audits and client walkthroughs.

What it does

  • Build a walkthrough from a report or pasted markdown in one click
  • Bake per-scene narration audio
  • Share a link or download a single-file HTML export
Price
Free
Version

Where it runs
Works on InfiniBot Cloud

How to start

  1. Install HoloCanvas from the marketplace.
  2. Pick a report (or paste markdown) and build a walkthrough.
  3. Narrate it, then share the link or the HTML file with your client.

What you need

  • Works on self-hosted InfiniBot and InfiniBot Cloud

Questions

Do share links break if I turn the plugin off?

No. The canvas runtime is part of InfiniBot core; turning the plugin off only hides the library.
