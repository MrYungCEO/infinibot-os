Robovoice

Give your agents a voice: characters, a speech pipeline and live calls.

Free
Get it freeStart on InfiniBot CloudOr run it yourself, free

Learn it step by step: AI Business Use-Cases course on KinglyVault

Who it's for

Businesses that want an AI receptionist or voice agents that answer with InfiniBot's brain.

What it does

  • Robovoice becomes InfiniBot's voice backend for every agent
  • Give each agent its own Robovoice character
  • Edit the speech-to-text, model and text-to-speech pipeline from InfiniBot
Price
Free
Version
2026.10.4
Where it runs
Works on InfiniBot Cloud
Publisher
InfiniBot (first-party)

How to start

  1. Install Robovoice from the marketplace.
  2. Link this install to your self-hosted Robovoice stack or Robovoice cloud.
  3. Map agents to characters and take a call.

Screenshots

What you need

  • A Robovoice self-hosted stack or a Robovoice cloud account
  • On Robovoice cloud, calls use your Robovoice wallet credits; self-hosted has no metering

Questions

Which model answers the call?

InfiniBot itself: a gateway agent or a CLI agent, streamed back for low-latency speech.
