Who it's for

Creators, faceless-content operators and designers who want their agents to generate visuals on their own AI keys.

What it does

  • FlyPic's studio embedded 1:1: image + video, references, aspect and quality
  • Agent tools: generate, wait for the job, reuse an item as a reference
  • Your FlyPic library inside InfiniBot: filter, download, favorite, reuse

How to start

  1. Install FlyPic from the marketplace (or unlock it with CEO).
  2. Click Connect FlyPic and approve on flypic.ai. Tokens are stored encrypted.
  3. Ask an agent for an image or a video, or open the Studio page and generate yourself.

What you need

  • A FlyPic account (connect in one click or paste a FlyPic API token)
  • Your own AI provider keys in FlyPic: it runs on them, not on InfiniBot credits
  • Agent access follows your FlyPic plan's MCP & API access

Questions

Do I pay InfiniBot credits for generations?

No. FlyPic runs on the AI provider keys in your FlyPic account.

Can I use it on InfiniBot Cloud?

Yes. The registry lists FlyPic as available on InfiniBot Cloud.

Where do I learn motion swap?

The Content Studio + FlyPic course has a Motion Swap lesson and a capstone that builds a motion-swap promo.
