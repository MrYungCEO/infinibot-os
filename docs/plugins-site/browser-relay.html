Browser Relay extension

Let agents work in your own logged-in Chrome, one tab you grant at a time.

Included with InfiniBot
Start on InfiniBot CloudOr run it yourself, free

Learn it step by step: InfiniBot Operator course on KinglyVault

Who it's for

Anyone whose work lives in web apps their agents need to use.

What it does

  • Agents act in tabs you explicitly grant, or tabs they create
  • No cookies, passwords or storage are exported to agents
  • Page text is treated as data, never as instructions
Price
Included with InfiniBot
Publisher
InfiniBot (built in)

How to start

  1. Install the InfiniBot Browser Relay extension in Chrome.
  2. Pair it with a one-time code.
  3. Grant the current tab, then ask an agent to do the task.

What you need

  • Google Chrome
  • A local InfiniBot gateway (the relay is loopback-only)
