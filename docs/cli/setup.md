# `infinibot setup`

Initialize `~/.infinibot/infinibot.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
infinibot setup
infinibot setup --workspace ~/clawd
```

To run the wizard via setup:

```bash
infinibot setup --wizard
```
