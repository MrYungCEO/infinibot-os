# `infinibot pairing`

Approve or inspect DM pairing requests (for channels that support pairing).

Related:
- Pairing flow: [Pairing](/start/pairing)

## Commands

```bash
infinibot pairing list whatsapp
infinibot pairing approve whatsapp <code> --notify
```
