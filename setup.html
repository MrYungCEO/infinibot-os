What's inside

Everything you'd duct-tape together, ready out of the box.

One install, one config file, one binary. Each subsystem lives behind a single tab in the UI.

Multi-session chat

Single-pane chat or multi-session grid. Bring your own model — Anthropic, OpenAI, local Ollama, anything OpenAI-compatible.

Voice in & out

Wake-word, push-to-talk, full duplex. TTS pipes back to whichever device summoned you.

Kanban & projects

Notion-synced tasks, drag-and-drop board, autonomous agents per task. Bound to discipline blocks for time-blocking.

Calendar + cron

Google Calendar & Calendly sync, plus a full cron scheduler for recurring agent jobs and workflow automations.

Discipline / time-blocking

Plan your day in blocks, get nudges via Telegram, score yourself nightly. Templates persist across days.

Self-improving skills

Cumulative skills package distills successful agent runs into reusable SKILL.md files and refines them over time.

Browser sandbox

Spawn headed or headless browser sessions per agent. Page snapshots, click, type, screenshot.

Markdown workflows

Reusable agent workflows authored as plain markdown with typed inputs, preflight checks, and run history.

Step 1

Install InfiniBot.

Pick the install path that matches your machine.

Install with npm

Needs Node 22.12 or later. Installs the gateway binary plus the UI to your user-global path.

npm install -g infinibot

Verify the install:

infinibot --version

Install with bun

Faster cold-start than Node. Note: bun is fine for general use, but use Node for WhatsApp/Telegram channel runtimes.

bun install -g infinibot

Run with Docker (build locally)

No prebuilt image is published yet (coming soon). Build the image from a clone of the repo; the compose file exposes the gateway on 18789 and keeps state in ~/.infinibot.

docker build -t infinibot:local .
docker compose up -d infinibot-gateway

Open http://localhost:18789 once it's up.

Desktop app

Download it from infinibotos.com/download: Windows 10/11 x64 (InfiniBot-Setup-x64.exe) and Linux x86_64 (InfiniBot-x86_64.AppImage or infinibot_amd64.deb). macOS is coming soon. Installed apps update themselves.

Windows may show a blue "Windows protected your PC" screen. Click More info, then Run anyway. This happens because InfiniBot is a new app that isn't code-signed yet, not because anything is wrong. Want to double-check? Compare the file's SHA-256 with the checksum on the download page (PowerShell: Get-FileHash .\InfiniBot-Setup-x64.exe).

Prefer not to install anything? Try InfiniBot Cloud in your browser (the Free plan, no card).

Step 2

Connect a model + a channel.

InfiniBot is BYOM (bring-your-own-model). Plug in any provider; pick at least one channel to talk to it through.

Add your model API key

Store credentials in ~/.infinibot/infinibot.json. Anthropic, OpenAI, Gemini, Ollama, and any OpenAI-compatible endpoint are supported. No key? Use a free local model (Ollama), or the free tiers of Google Gemini or Groq.

{
  "providers": {
    "anthropic": { "apiKey": "sk-ant-..." },
    "openai":    { "apiKey": "sk-..." },
    "ollama":    { "baseUrl": "http://localhost:11434" }
  },
  "defaultModel": "anthropic/claude-sonnet-4-6"
}
Tip · The Settings panel in the UI writes the same file. You can edit it by hand or click your way through.

Wire up a channel

A channel is how the agent reaches the world: WhatsApp, Telegram, Discord, Slack, Signal, iMessage, or just the in-app chat.

  • Telegram: paste a bot token from @BotFather.
  • WhatsApp: scan the QR shown on first run (Baileys-based).
  • Discord: bot token + server invite.
  • iMessage / Signal: companion bridge runs on macOS.

Set the bot token via the Channels page in the UI, or directly:

infinibot config set channels.telegram.botToken "123:ABC..."

(Optional) Connect Notion, Google Calendar, GitHub

Each integration shows up as its own tab in the UI with a one-click OAuth flow. The Calendar page handles Google + Calendly; the Kanban page reads/writes a Notion database; the Workspace page can wire to GitHub repos.

Privacy · Tokens are stored locally under ~/.infinibot/. They never leave your machine unless you explicitly enable cloud sync.
Step 3

Start the gateway.

One command spins up the WebSocket gateway, the channel adapters, and the web UI.

Run it

infinibot start

Open the UI at http://127.0.0.1:18789. The terminal logs ping you when each subsystem is ready.

Common commands

infinibot start              # run the gateway in the foreground
infinibot start --daemon     # run detached (logs to ~/.infinibot/logs/)
infinibot stop               # stop a daemon
infinibot status             # health, uptime, channels, model
infinibot logs --tail 100    # tail recent gateway logs
infinibot config show        # print resolved config
infinibot doctor             # verify env, ports, providers, channels
Port in use? · The default gateway port is 18789. Override with --port or by setting gateway.port in your config.
Tool surface

What the agent can actually do.

Every tool below is wired through the gateway and exposed to your model via MCP. Disable individually in tool-policy.

message.send
Send to any channel — WhatsApp, Telegram, Discord, Slack, Signal, iMessage.
cron.add / list / run
Schedule one-shot, interval, or cron-expr jobs. Isolated or main session.
workflows.run
Execute a markdown workflow with typed inputs + preflight gates.
kanban.tasks.*
Notion-backed kanban CRUD. Drag tasks onto discipline blocks for time-boxing.
browser.run
Headed/headless browser session per agent. Snapshot, click, type, screenshot.
research.*
Brave / Exa / web fetch under one interface. Rate-limited per-provider.
tts / vision
Speak responses, analyze image attachments, OCR documents.
memory.*
Per-agent persistent memory + cumulative skill capture.
canvas.*
Generative UI surface — agent renders interactive widgets back to you.
Questions

Frequently answered.

Is it safe?

The Windows installer isn't code-signed yet, so Windows may show "Windows protected your PC" (click More info, then Run anyway), and you can verify the file's SHA-256 checksum on the download page. InfiniBot runs on your computer, and Secure Mode keeps chats on local models only. The source is available under the FSL-1.1-ALv2 license.

Do I need an API key?

No. Sign in with the Claude, ChatGPT, Google or Grok plan you already have (desktop app), run a free local model (Ollama), or use a provider's free tier (Google Gemini, Groq).

What does it cost?

The desktop app and self-hosting are free. Cloud plans run from Free ($0) to $199/mo. Some plugins are a one-time purchase ($19 to $49). Your own AI provider bills you separately, or a local model is $0.

Is there a Mac app?

Coming soon. For now, use InfiniBot Cloud in your browser, or npm i -g infinibot (Node 22.12+) on a Mac.

Does my data stay on my machine?

The gateway, UI, scheduler, kanban, and skills system all run on your machine. The only network calls go to (a) your chosen LLM provider and (b) external services you opt into — Notion, Google Calendar, channel APIs, etc. Tokens and conversation history stay under ~/.infinibot/.

Which model providers are supported?

Anthropic (Claude), OpenAI (GPT), Google (Gemini), and any OpenAI-compatible endpoint — including local Ollama, LM Studio, and vLLM deployments. Per-job model overrides let you mix cheap local inference for routine work with frontier models for hard problems.

Can I run multiple agents at once?

Yes. The grid view runs N parallel sessions side-by-side. Each agent has its own workspace, skills, and tool policy. Schedule them via cron, or trigger them from a workflow / channel message.

How do I add a custom skill?

Drop a folder containing a SKILL.md (with YAML frontmatter) into ~/.infinibot/skills/ or <workspace>/skills/. The watcher hot-reloads it. The cumulative-skills system also auto-distills successful runs into new skills you can review and refine.

Where do logs and state live?

Everything mutable lives under ~/.infinibot/ by default — config, tokens, kanban DB, cron jobs, run history, skills, memory. Override with INFINIBOT_STATE_DIR if you want it elsewhere. Logs land in ~/.infinibot/logs/.

How do I update?

The desktop app updates itself. For npm, re-run your installer: npm install -g infinibot@latest (or bun install -g infinibot@latest). If you built the Docker image, pull the latest code and rebuild it. State on disk is forward-compatible across minor versions; the changelog flags any breaking migrations.

Telegram says "unknown method: message.send" — what now?

That's the legacy method name. The current gateway exposes the action as send with params { channel: "telegram", to: "<chatId>", message, idempotencyKey }. If you hit it from a custom integration, update the method name; the in-app UI is already on the new shape.

Can the agent see my screen / control my computer?

Only when you explicitly grant it via the screen-analyze, mouse, and exec-approval tools. By default everything destructive is gated behind an approval prompt; you can bulk-allow patterns once you trust a workflow.
