InfiniBot

Welcome to InfiniBot

InfiniBot is your personal AI gateway — agents, voice calls, kanban, multi-channel messaging, and more, all running locally on your machine. This wizard will get you set up in under 2 minutes.

  • Your data stays local (gateway runs at 127.0.0.1:47913)
  • Voice runs on Robovoice — nothing to install on this machine
  • You can reconfigure any time from the Settings panel

Voice Optional

Voice runs on Robovoice — calls, speech-to-text and text-to-speech are handled there, so nothing is installed on this machine. Linking is optional: open the Voice page in the app after launch (or use Open Voice in the tray menu), or run infinibot robovoice login from a terminal.

AI Provider Required

InfiniBot needs at least one LLM provider. You can configure API keys inside the app's Quickstart / Settings screens after launch — this step is just a reminder. All credentials are stored locally in ~/.infinibot/infinibot.json.

  • Anthropic Claude (recommended) — ANTHROPIC_API_KEY
  • OpenAI — OPENAI_API_KEY
  • Google Gemini — GEMINI_API_KEY
  • CLI fallback — Claude Code / OpenCode / Codex (no API key needed)

All Set — Launch InfiniBot

Click Launch to start the gateway and open the dashboard. The app will live in your system tray — closing the window keeps the gateway running.
