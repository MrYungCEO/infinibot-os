# Gateway RPC Surface Audit

_Analysis-only report. Generated by a static + runtime cross-reference of the gateway handler map, the advertised capability list, and every call site in `ui/src`. No behaviour was changed._

## Method

**Served set (1,922 methods).** Taken from `Object.keys(coreGatewayHandlers)` on the built `dist/gateway/server-methods.js` (built after the current `src`, so it reflects the working tree), union:
- `createExecApprovalHandlers(...)` — merged at runtime as `extraHandlers` in `src/gateway/server.impl.ts:733`, so `exec.approval.request` / `exec.approval.resolve` **are** served even though they are absent from `coreGatewayHandlers`.
- Plugin-registered methods (`api.registerGatewayMethod`) from `extensions/infinicode/index.ts` and `extensions/voice-call/index.ts` — served only when the plugin is enabled.

A static brace-depth parse of every `*Handlers` object literal under `src/gateway/server-methods/**` produced 1,572 keys, all of which are a strict subset of the runtime set — the two agree, so no stale-`dist` skew was found. Every finding below was additionally re-verified with a whole-repo literal grep over `src/`, `extensions/`, `electron/`, `mobile/`, `scripts/`.

**Advertised set (887 methods).** String entries of `BASE_METHODS` in `src/gateway/server-methods-list.ts`. The `GATEWAY_EVENTS` array at the bottom of that file is **excluded** — those are broadcast event names, not methods, and 17 of them would otherwise show as false positives.

**UI call sites.** Two passes over `ui/src/**`: (a) `\brequest(<literal>` for direct calls, (b) *every* method-shaped string literal, which catches indirection tables such as the `INVOICE_METHODS` capability→candidate map in `ui/src/ui/controllers/agency-invoicing.ts:61`. Comment lines are skipped. There are no template-literal `request(\`...\`)` call sites in `ui/src`, so no dynamically-composed method names to account for.

**Dispatch fallback.** `src/gateway/server-methods.ts:1496` looks up `extraHandlers[method] ?? coreGatewayHandlers[method]` and otherwise replies `INVALID_REQUEST: unknown method: <m>`. There is no alias table and no catch-all, so every Table 3 entry is a hard runtime error.

**Not treated as a bug:** being served without being advertised. The `reports.*` family and many others dispatch fine while absent from `server-methods-list.ts`; the list is only a capability advertisement.

### Caveat

A method with no static caller is not necessarily uncallable — an operator can invoke any RPC by name over the websocket, and some of these are plausibly reachable through generic tooling. The claim made here is narrower and checkable: **no code in this repository calls them.**
